# Cursa — live preview

A personality-driven cursor (an arrow with eyes). This is the browser preview of
the desktop app. On a phone, **drag to move** the cursor and **tap to click**.
Use the **Cursa Dev** panel to try every case (age stages, site/app contexts,
one-shot events, held states, poses). Give a context ~4–5s of stillness to see
held-object actions (coffee sip, popcorn eat, etc.).
